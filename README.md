# Hello, I'm Rok

I am focused on quantitative finance, risk management, and actuarial modeling. I enjoy using Python and R to solve practical financial problems, analyze data, and build clear, clean, and reliable tools.

---

## Projects

### Solvency II Motor Insurance Actuarial Model
* A Python and R project for estimating insurance reserves and regulatory capital requirements under Solvency II.
* Uses an SQLite database for data management and features an interactive Streamlit web application.
* [View Repository](https://github.com/klepecvabicrok/Solvency-II-Motor-insurance-Actuarial-Reserve-Model-2026)

### Quantitative Risk & Return Optimizer
* A portfolio optimization tool in Python that balances expected returns with downside risk metrics (VaR and CVaR).
* Includes independent R verification scripts to ensure calculation accuracy.
* [View Repository](https://github.com/klepecvabicrok/Quantitative-Risk-Return-Optimizer)
